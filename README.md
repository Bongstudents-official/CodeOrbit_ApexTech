# Apex Tech Solutions — Corporate Cloud & AI Landing Page

A responsive, multi-page enterprise technology landing website built with **Bootstrap 5**, custom CSS animations, and **Vanilla JavaScript** as Task 2 of the **CodeOrbit Tech Web Development Virtual Internship (Batch 3)**.

## 🔗 Links

- **GitHub Repository:** [https://github.com/Bongstudents-official/<your-repo-name>](https://github.com/Bongstudents-official/<your-repo-name>)

## 🛠️ Technologies Used

- **HTML5:** Multi-page semantic layout (`index.html` and `contact.html`) with Bootstrap ScrollSpy and accessible ARIA attributes.
- **Bootstrap 5.3 & Bootstrap Icons:** Responsive 12-column grid system, collapsible sticky navbar, progress bars, and utility classes.
- **CSS3:** Custom properties (`:root` variables), glassmorphism backdrop filters, `@keyframes` shooting star and firefly animations, floating cards, and an infinite client marquee.
- **Vanilla JavaScript (ES6+):** Smooth anchor scrolling, automatic mobile navbar collapse on link click, and client-side contact form validation with timed success alerts.

## ✨ Key Features

- **Glassmorphic Navigation & Hero Section:** Sticky translucent navbar paired with an animated shooting-star hero banner and floating live system analytics card.
- **Features, Services & Impact Metrics:** Responsive Bootstrap grid showcasing core capabilities, technical services, and key company milestones.
- **Testimonials & Infinite Marquee:** Client review cards accompanied by a continuous CSS-animated partner marquee.
- **Dedicated Contact Page (`contact.html`):** Full inquiry form with real-time Bootstrap/JS field validation and live confirmation feedback.
- **Animated Dark Footer:** Multi-column footer enhanced with ambient CSS firefly particles and quick navigation links.

## 📂 Project Structure
